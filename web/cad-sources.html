Component integrity and changes

The viewport component is compiled from upstream commit 0e77cae652271d08c7619238e619f9b6668ae17c. The source patch removes the application chrome in host mode and exposes viewport/layout state. Drawing, native records, picking, history and file readers/writers remain in the engine. Analytics and the component service worker are disabled, and network connections are restricted to this host.
