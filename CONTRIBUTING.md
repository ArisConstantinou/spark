# SparkWorld development

SparkWorld is an electrical drafting workspace created by Aris. Keep the graphite and cobalt visual theme, the desktop sidebar and the compact mobile bottom navigation.

Keep original CAD bytes intact. Rendering, editable annotations, source-object edits and native export must be tested independently. A selected CAD object must expose its source identity; rendered primitives are not independent source objects when they belong to one block instance.

Do not add invented projects, simulated progress, inactive controls or decorative placeholder content. Keep adjacent controls aligned and all text readable. App confirmations and desktop window controls use the application theme.

Test with synthetic public fixtures and user-authorized local CAD files. Never commit private drawings, screenshots of private drawings, local browser profiles, credentials or operational machine configuration. Local fixture paths belong in environment variables.

Publish only verified artifacts. Record browser interaction timing separately from background CAD raster refinement. Web and desktop packages must open and preserve the same portable project format.
